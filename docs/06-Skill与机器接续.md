# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-subtitle-studio`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取固定媒体与已有字幕→预览格式和转换损失→导入或维护明确时间→双语条目关联→实际播放检查→按固定条目反馈及返工→导出并复核SRT/VTT/ASS。

方法入口为[SKILL](../skills/hetu-subtitle-studio/SKILL.md)，[操作地图](../skills/hetu-subtitle-studio/references/operations.md)随清单生成，[流程](../skills/hetu-subtitle-studio/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。实际识别、翻译、配音和烧录由作者选择的外部Agent工具完成。本包不伪造逐字时间，不把估计对齐标为人工核准。v1读取SRT、VTT及ASS基础Dialogue；样式、特效、定位与格式控制可能损失，预览明确报告，不声称完整ASS往返。
